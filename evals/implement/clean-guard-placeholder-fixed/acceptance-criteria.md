- AC13: The push guard blocks, in a registered repo, any `gh issue edit` with `--remove-parent`, `--remove-sub-issue` or `--remove-label` naming `feature`, `gh label delete feature`, and any `gh api` call that removes a sub-issue (`removeSubIssue` in a GraphQL query, or a DELETE on a `sub_issue` path) or deletes the `feature` label from an issue or repo (a DELETE on a path ending in `labels/feature`). Its message says a feature's label and sub-issue links are never removed by a session and that the user changes them by hand on GitHub. Other `gh issue edit` calls are still allowed.
